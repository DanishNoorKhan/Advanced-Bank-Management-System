# 🏦 Advanced Bank Management System in C++

A console-based banking application developed in C++ to demonstrate Object-Oriented Programming (OOP), account management, banking transactions, and core software development concepts.

## 📌 Overview

The Advanced Bank Management System simulates basic banking operations through a menu-driven console interface. It demonstrates the use of C++ programming concepts to organize and manage banking-related tasks.

## ✨ Features

- Account Creation and Management
- Customer Information Management
- Deposit and Withdrawal Operations
- Balance Inquiry
- Money Transfers Between Accounts
- Transaction History
- Input Validation and Error Handling
- Menu-Driven Console Interface

> **Note:** The features listed above should match the functionality implemented in the source code.

## 🛠️ Technologies Used

- **Language:** C++
- **Core Concepts:** Object-Oriented Programming (OOP)
- **IDE:** Visual Studio Code
- **Compiler:** GCC (g++)

## 🚀 Getting Started

### Prerequisites

- A C++ compiler, such as GCC.
- Git installed on your system.
- A code editor, such as Visual Studio Code.

### 1. Clone the Repository

```bash
git clone https://github.com/DanishNoorKhan/Advanced-Bank-Management-System.git
```

### 2. Navigate to the Project Directory

```bash
cd Advanced-Bank-Management-System
```

### 3. Compile the Program

If the main source file is named `main.cpp`, run:

```bash
g++ main.cpp -o bank
```

### 4. Run the Program

On Windows:

```bash
bank.exe
```

On Linux or macOS:

```bash
./bank
```
